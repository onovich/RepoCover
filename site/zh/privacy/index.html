隐私

RepoCover 不经营仓库数据服务。

这份政策说明开源 Skill、静态文档网站，以及你可能与它们一起使用的第三方服务之间的边界。

生效日期：2026 年 8 月 14 日

Skill

RepoCover 在你使用的 Codex 环境中运行。这个开源项目不会接收、存储或出售你检查的仓库内容。Codex 提供方、GitHub、浏览器、模型提供方与其他连接工具，可能按照各自的条款和隐私政策处理数据。

网站

这是一个静态 GitHub Pages 网站。RepoCover 不添加分析服务、广告、跟踪像素、账号注册或联系表单。语言切换器可能在浏览器本地存储一项偏好。GitHub 可能按照 GitHub 隐私声明处理托管日志与请求。

你的仓库

除非当前 Codex 与 GitHub 权限适合处理这些数据，否则不要提供密钥、凭据、个人数据或私有源码。发布前请检查生成图片，因为封面可能暴露仓库证据中的文字或图像。

政策更新

重大变化会在本页公布，并更新生效日期。问题可以通过 GitHub Issues 提出。
