支持

带上仓库，说清楚哪里不对。

RepoCover 是开源项目。安装问题、可以复现的生成问题和输出校验错误，都通过 GitHub Issues 处理。

寻求帮助

在 RepoCover Issue 区提交问题。为了更快定位，请附上 Codex 版本、操作系统、本地或远端证据模式、使用的提示词，以及校验输出。

视觉质量反馈

可以附上生成的封面，并指出一个具体缺陷：比如裁切挡住了玩法、3D 变成了扁平图形、连线没有端点，或缩略图文字无法阅读。不要提交私有源码或密钥。

安全问题

涉及安全的问题，请遵循仓库的安全策略，不要直接创建公开 Issue。
