RepoCover 案例

8 个仓库，各有各的封面。

每张封面都采用 GitHub Social Preview 的 1280×640 规格，并控制在 1 MB 以内。除此之外，设计会围绕各自项目最有辨识度的部分展开。

项目特征 · 3D

PrismDraft

一个平涂 3D 建模库。封面保留了多面体的空间感，没有把它变成普通的平面几何图案。

真实界面 · Web 工具

LittlePNG

真实界面仍然清楚可认，但浏览器杂项被去掉，任务队列也重新排成了更适合小图分享的画面。

核心视觉 · 桌面应用

DeskMochi

这个桌面陪伴角色本来就很有辨识度，因此封面保留了它，并围绕它重新组织构图。

真实流程 · 音频工具

AudioTrim

波形、选区和导出状态，比装饰性的音乐符号更能讲清楚这个游戏音频裁切工具。

无现成图片 · 程序库

Beat

仓库里没有适合直接做封面的图片，因此把频率能量、阈值、冷却和事件回调变成了画面的核心。

流程结构 · Codex Skill

JustGoal.skill

分支、并行审查、合并门禁和修复循环决定了图形，每条连线都对应真实步骤。

项目几何 · 程序库

Knot

几何关系来自这个库本身对重叠与投影的研究，并不是为了装饰而额外添加。

素材有限 · 适度重构

Ping

可用的运行画面很少，因此只做了必要的重构：把交互讲清楚，但不凭空添加数据面板或不存在的功能。

试试你的仓库

方向由项目本身决定。

RepoCover 会先看项目里已经有什么，再决定怎么呈现。如果项目能在本地运行，请保持预览可用，让它看清真实界面。
