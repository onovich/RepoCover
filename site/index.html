About

Many programmers are better at building than packaging their work. I am one of them.

As AI makes it easier to build more, a clear first impression may be what makes someone stop and look.

That is how RepoCover came to be. I made it in a day. It looked pretty good, so I started using it myself.

Start with what the project has

A screenshot can be a reference. It is not always the best cover.

RepoCover keeps the useful parts, removes clutter, and recomposes the scene so it still works as a small link preview.

Three starting pointsRepoCover uses whichever one matches your project.
No project needs all three.
A When the project has

A working interface

Keep the recognizable interaction, crop around what matters, and remove browser chrome, debug clutter, or broken fragments.

B When the project has

A brand or main visual

Keep its character, dimensionality, and color language, then rebuild the surrounding layout for a clearer cover.

C When the project has

No suitable image

Build a visual direction from what the project does and how it works, without inventing features or pretending an earlier cover exists.

How it works

Read first. Draw second.

01

Read the project

Review the README, key code, project rules, screenshots, and visuals already in the repository.

02

Check what is usable

Decide whether there is enough to make an honest cover, what to use, what is missing, and what should stay out.

03

Recompose

Keep the project's recognizable parts, remove clutter, and arrange the cover around one clear idea.

04

Check the result

The final SVG and PNG are reviewed at full size and as 320×160 thumbnails on both light and dark backgrounds.

Quick start

Use RepoCover in Codex—or another compatible AI coding tool.

Codex is the recommended option. Other tools that can install and run Skills can use RepoCover too. Open a local repository or provide a remote repository URL.

Install
Install the Skill from https://github.com/onovich/RepoCover.
Use
Use $repo-cover to create a cover for the current project.

RepoCover writes an editable SVG and exact 1280×640 PNG by default. It does not edit your README, upload the image, or change repository settings unless you ask separately.

Questions

What you may want to know.

Does it work without a screenshot?

Yes. RepoCover can derive a visual direction from what the repository contains, but it will not invent an interface or claim features it could not verify.

Can it use an existing web app?

Yes. An accessible local preview or working frontend usually produces the strongest result because the real interface can be inspected and selectively recomposed.

Does every cover look alike?

No. Every cover follows the same GitHub-ready output rules, but its subject, colors, dimensionality, and layout come from the current project.

Will it upload the image to GitHub?

Only when separately requested. Creating the files and changing repository settings are two different authorization boundaries.
