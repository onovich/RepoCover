Support

Bring the repository. Describe the mismatch.

RepoCover is open source. Installation questions, reproducible generation problems, and output-validation bugs are handled through GitHub Issues.

Ask for help

Open an issue in the RepoCover issue tracker. For faster diagnosis, include the Codex version, operating system, local or remote evidence mode, the prompt you used, and the validation output.

Visual quality feedback

Attach the generated cover and identify one concrete defect: for example, a crop hides the interaction, 3D identity became flat, a connector has no endpoint, or thumbnail text is unreadable. Do not include private source files or secrets.

Security reports

For security-sensitive reports, follow the repository's security policy instead of opening a public issue.
