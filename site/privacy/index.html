Privacy

RepoCover does not operate a repository-data service.

This policy explains the boundary between the open-source Skill, the static documentation site, and the third-party services you may use with them.

Effective 14 August 2026

The Skill

RepoCover runs inside the Codex environment you use. The open-source project does not receive, store, or sell the repository contents you inspect. Your Codex provider, GitHub, browser, model provider, and other connected tools may process data under their own terms and privacy policies.

The website

This is a static GitHub Pages site. RepoCover does not add analytics, advertising, tracking pixels, account registration, or a contact form. The language switcher may store one preference in your browser's local storage. GitHub may process hosting logs and requests under the GitHub Privacy Statement.

Your repositories

Do not provide secrets, credentials, personal data, or private source material unless your active Codex and GitHub access are appropriate for that data. Review generated images before publishing them; a cover can expose text or imagery found in the repository evidence.

Changes

Material changes will be published on this page with a new effective date. Questions can be raised through GitHub Issues.
