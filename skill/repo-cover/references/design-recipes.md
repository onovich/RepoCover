# RepoCover reference index

This file remains as a compatibility entry point for older prompts. New runs should follow the conditional routing in `SKILL.md` and load only the relevant files:

- [`common-quality.md`](common-quality.md): universal layout, relevance, line, copy, chart, and rejection gates.
- [`source-material.md`](source-material.md): screenshots, runtime captures, repository artwork, extraction, reconstruction, and seam integrity.
- [`cold-start.md`](cold-start.md): first-use generation when no usable primary visual exists.
- [`version-regression.md`](version-regression.md): preservation contracts, versioned candidates, comparison, and promotion.
- [`design-ledger-template.md`](design-ledger-template.md): reusable evidence and review record.

Do not load every route when only one applies.
